# Smart Finance 0.1

Esta é a primeira base funcional do projeto.

## Pronto para uso e evolução

- Backend modular em Python/FastAPI.
- Frontend modular em React/TypeScript.
- Banco SQLite local e separado por usuário.
- Conta administrativa padrão solicitada.
- Cadastro, login, chave de recuperação e troca de senha.
- Administração de usuários, permissões e acesso aos dados financeiros selecionados.
- Rendas, despesas, recorrências, parcelamentos, contas, cartões, faturas e empréstimos.
- Categorias personalizadas e ocultáveis.
- Comprovantes armazenados fora do banco.
- Dashboard, alertas e relatório PDF mensal.
- Backup diário consistente, incluindo banco e comprovantes.
- Acesso pela rede local e anúncio `smartfinance.local` por mDNS.

## Etapas futuras já previstas

- APK Android com banco SQLite próprio.
- Importação e restauração de backups pela interface.
- Sincronização opcional entre computador e celular.
- Edição avançada de séries recorrentes e parcelamentos.
- Livro-caixa completo para calcular saldo real de cada conta.
- Testes automatizados mais amplos.
