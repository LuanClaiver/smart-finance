# Smart Finance 0.1.5

## Correções

- Removida a chamada desnecessária a `reset()` depois de salvar rendas, despesas, contas, cartões e empréstimos.
- Formulários de configurações agora utilizam referências seguras do React para serem limpos.
- Adicionado bloqueio de cache na interface para impedir que o navegador reutilize JavaScript de versões anteriores.
- Os arquivos `app.js` e `styles.css` agora recebem o identificador de versão `0.1.5`.
- O pacote de atualização não contém o banco de dados.
