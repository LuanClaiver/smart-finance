# Identidade visual Smart Finance

A nova marca combina uma carteira digital com um gráfico ascendente. A carteira representa organização financeira; a linha de crescimento representa decisões melhores; o ponto com sinal de mais reforça o aspecto inteligente e proativo do sistema.

Arquivos principais:
- `smart-finance-logo.svg`: versão vetorial oficial.
- `smart-finance-logo-1024.png`: versão PNG em alta resolução.
- `smart-finance-logo-foreground-1024.png`: primeiro plano para ícone adaptativo Android.

Os ícones do site, do PWA, da interface e do APK Android são atualizados automaticamente pelos arquivos e scripts do projeto.
