SMART FINANCE 0.4.0 — TESTES DA IMPORTAÇÃO
Data: 26/07/2026

Correção aplicada
- A importação não tenta mais renomear/substituir o arquivo smart_finance.db em uso.
- O banco selecionado é restaurado pelo mecanismo de backup do próprio SQLite.
- Todas as conexões SQLite temporárias são fechadas explicitamente.
- Arquivos temporários não podem mais transformar um sucesso em erro 500 durante a limpeza.
- A resposta HTTP é enviada antes de o processo ser encerrado para reinicialização.
- Erros do backend agora aparecem com o detalhe real, em vez da mensagem genérica.

Observação
O ambiente de teste não é Windows. A alteração foi feita justamente para eliminar a operação que dependia de renomear um SQLite bloqueado pelo Windows. A restauração agora usa a API oficial de backup do SQLite, que foi testada de ponta a ponta com servidor ativo e reinicialização automática.
