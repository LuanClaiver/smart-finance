SMART FINANCE 0.2.1 - RESTAURAR SEUS DADOS

Este pacote contem o codigo completo, mas nao contem um banco de dados.
Isso evita substituir o arquivo smart_finance.db que voce salvou.

PASSO A PASSO

1. Extraia todo o ZIP para uma pasta nova.
2. Execute "Restaurar Banco Salvo.bat".
3. Informe o caminho do seu arquivo smart_finance.db salvo.
   Tambem e possivel arrastar o banco para cima do arquivo BAT.
4. Depois da confirmacao, execute "Iniciar Smart Finance.bat".
5. Na primeira execucao, o ambiente sera preparado uma unica vez.
6. Nas proximas aberturas, use Iniciar Smart Finance.bat para iniciar rapidamente.

LOCAL CORRETO DO BANCO

backend\data\smart_finance.db

IMPORTANTE

- Nao renomeie o banco depois de restaura-lo.
- Nao execute duas copias do Smart Finance usando o mesmo banco ao mesmo tempo.
- O pacote inclui o frontend compilado e todo o codigo-fonte React/TypeScript.
- Node.js so e necessario para alterar e recompilar o frontend.
